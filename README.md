#  ToDo List App

A simple and user-friendly ToDo List application built with Flutter. The app helps users organize daily tasks, track progress, and improve productivity.

##  Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and intuitive user interface
- Cross-platform support with Flutter

##  Technologies Used

- Flutter
- Dart
- Material Design

##  Project Structure

```text
lib/
├── main.dart
├── screens/
├── widgets/
├── models/
└── services/
```

 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/ToDoList.git
```

2. Navigate to the project directory:

```bash
cd ToDoList
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
